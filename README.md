## SSD、NVMe 和普通 SSD VPS 到底差在哪

SATA III 接口的理论上限是 6Gbps，普通 SATA SSD 的顺序读写大约 500 MB/s，4K 随机 IOPS 通常在几万级别。PCIe 4.0 NVMe 的顺序读写能到 3500 MB/s 左右，4K 随机 IOPS 可以破百万。这是接口和协议带来的差距，不是厂商调优能追平的。

但随机读写才是日常使用里感受得到的部分。静态页面、缓存做好的站点、纯代理转发，磁盘压力很小，NVMe 和 SATA SSD 的差别不容易察觉。数据库、高并发 API、动态 WordPress、Docker 镜像拉取这类会发出大量小体积读写请求的场景，NVMe 的响应优势才明显。

所以有一条反向建议值得说清楚：如果你只是挂一个静态站、跑个探针、做纯转发，SATA SSD 的便宜 VPS 就够用，不必为 NVMe 多付钱。RackNerd 的 Linux 促销档全系 NVMe，价格本身已经压到年付 20 美元附近，这个前提下选它没有额外溢价；但如果你看到别的商家 NVMe 比 SATA 贵出一截，而你的用途又碰不到随机读写，那笔差价可以省。
